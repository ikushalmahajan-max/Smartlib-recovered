2. Component Detailed Breakdown

🌳 Component 1: Binary Search Tree (BST)
Used In: Tab 2 (Book Catalog) & Tab 6 (Book Management)
Source File: ds/bst.py | cpp_engine/main.cpp
Functionality: Stores books sorted by Book ID. Enables $O(\log N)$ binary searching and $O(N)$ sorted in-order catalog traversals.
⚡ Component 2: Hash Table with Separate Chaining
Used In: Tab 3 (Fast ISBN Lookup)
Source File: ds/hash_table.py | cpp_engine/main.cpp
Functionality: Computes polynomial rolling hash values for 13-digit ISBN strings and handles bucket collisions using linked lists for instant $O(1)$ lookup.
🔗 Component 3: Singly Linked List
Used In: Tab 4 (Borrowing History Log)
Source File: ds/linked_list.py | cpp_engine/main.cpp
Functionality: Dynamically connects transaction nodes via pointers without pre-allocated fixed memory limits.
⏳ Component 4: Linked Queue (FIFO)
Used In: Tab 5 (Book Reservation Queue)
Source File: ds/queue.py | cpp_engine/main.cpp
Functionality: Maintains strict First-In, First-Out (FIFO) queue for student book reservation requests.
🤖 Component 5: Hybrid AI Recommendation Model
Used In: Tab 1 (AI Recommendations)
Source File: ml/recommender.py
Functionality: Combines Content-Based Filtering (TF-IDF + Cosine Similarity) and Collaborative Filtering (User-Item matrix) to recommend books based on borrowing history.
💾 Component 6: Datasets & Persistent Files
Used In: System Data Storage
Source File: data/books.csv | data/users.csv | data/borrowing_history.csv
Functionality: Stores persistent records for books, student profiles, and historical borrowing transactions.
