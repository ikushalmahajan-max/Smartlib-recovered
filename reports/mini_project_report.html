1. Abstract

This mini project presents an AI-Based Library Recommendation System developed for Second Year Engineering students at NMIET (Department of E&TC / Data Structures). The system combines core Data Structures (Singly Linked List, Binary Search Tree, Hash Table with Separate Chaining, FIFO Queue) for dynamic library inventory management with a Hybrid Machine Learning Recommendation Engine. The software incorporates Content-Based Filtering (TF-IDF vectorization + Cosine Similarity) and Collaborative Filtering (User-Item Interaction matrix) to recommend books based on student borrowing history. Both an interactive Streamlit Web Application and a pure C++ Engine were implemented and verified through automated unit testing.

2. Problem Statement & Objectives

2.1 Problem Statement

"To design and implement a high-performance Library Management and Recommendation System that utilizes fundamental Data Structures (Linked List, BST, Hash Table, Queue) for optimal data storage and retrieval, and incorporates AI/ML techniques to predict student borrowing preferences and recommend relevant books based on past borrowing history."

2.2 Key Objectives

  • Dynamic Catalog Search: Implement a Binary Search Tree (BST) to index books by unique Book ID, enabling $O(\log N)$ search time complexity and $O(N)$ sorted in-order catalog traversals.
  • Instant ISBN Lookup: Implement a Hash Table with separate chaining collision resolution for $O(1)$ constant time ISBN queries.
  • Chronological Audit Trail: Implement a Singly Linked List to track user loan records and transaction history dynamically.
  • Reservation Management: Implement a FIFO Queue to manage reservation queues when requested books are checked out.
  • AI Recommendation Engine: Develop a hybrid recommendation algorithm combining Content-Based TF-IDF cosine similarity and Collaborative user borrowing matrix similarity.

4. AI/ML Recommendation Methodology

The AI recommendation engine generates personalized book recommendations based on user borrowing history using a Hybrid Scoring Formula:

Score_Hybrid(u, b) = 0.6 × Sim_Content(u, b) + 0.4 × Sim_Collab(u, b)

1. Content-Based Filtering: Calculates TF-IDF vectors from book metadata (genres, authors, descriptions) and measures cosine similarity against candidate books.
2. Collaborative Filtering: Builds a binary user-item matrix of borrowing transactions to calculate user-user similarity matrices.
